# DucTool Studio 🚀

Hệ thống công cụ học tập và làm bài thi tự động SEB thông minh tích hợp Google Gemini AI.

## Danh sách công cụ:
1. **Tool SEB v1** (`seb`): Giải bài thi trắc nghiệm giao diện SEB tiêu chuẩn.
2. **Tool SEB full màn v2** (`fullscreen`): Giải bài thi trắc nghiệm chế độ toàn màn hình.
3. **Tool Chụp Màn V2 -> SEB writing** (`seb_writing`): Chuyên giải bài tự luận, viết essay, gom ảnh và bôi đen đề (`Ctrl+Shift+R`) nối tiếp ngữ cảnh bản nháp tự động gõ vào SEB.
4. **Tool Gửi Đề -> Đáp Án Về Clipboard** (`file_solver`): Giải đề từ tệp file văn bản.
5. **Mở SEB_VIP** (`seb_vip`): Tải, giải nén và kích hoạt Safe Exam Browser VIP.
